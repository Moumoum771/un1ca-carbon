## 📲 Installation Instructions (TWRP)

1. Boot into TWRP Recovery.
2. Go to **Wipe > Format Data**, type `yes`, and confirm.
3. Transfer `UN1CA_Carbon_IX_1.0_dm1q_ZZI8.zip` to `/sdcard/` via USB MTP or use USB-OTG / ADB Sideload.
4. Go to **Install**, select the ZIP, and swipe to flash.
5. Tap **Reboot System**.
